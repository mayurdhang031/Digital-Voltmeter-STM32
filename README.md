# Digital Voltmeter using STM32

## Overview
A digital voltmeter PCB designed using KiCad and based on the STM32 microcontroller. The system measures DC voltage and displays the measured value in real time.

## Features
- STM32 Microcontroller
- DC Voltage Measurement
- KiCad PCB Design
- 2-Layer PCB
- Embedded C Firmware

## Software Used
- KiCad
- STM32CubeIDE
- Embedded C

## Hardware
- STM32 Microcontroller
- Voltage Divider Circuit
- Resistors
- Capacitors
- Crystal Oscillator
- Power Supply
